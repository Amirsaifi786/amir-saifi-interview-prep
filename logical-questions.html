How to answer these questions well

  • Explain your approach before coding or reasoning
  • Discuss edge cases and constraints
  • Compare brute force versus optimized solutions
  • Talk about time complexity and space complexity
  • Use simple, confident language

Top logical questions

Question What they test Good approach
Find the second highest number in an array.Logic and edge casesScan once while tracking top two values.
Check if two strings are anagrams.Hashing and frequency countingCompare character counts or sort both strings.
Find the first non-repeating character in a string.Frequency mapUse counts and first occurrence index.
Find duplicates in an array.Set or hashingTrack seen values and report duplicates.
Reverse a string without using extra space.In-place manipulationSwap characters from both ends.
Check if a string is a palindrome.Two pointersCompare characters from both ends.
Merge overlapping intervals.Sorting and groupingSort by start and merge when overlapping.
Find the longest substring without repeating characters.Sliding windowUse a window and a set/map for last seen positions.
Find the maximum subarray sum.Dynamic programming / KadaneKeep running sum and best sum.
Validate balanced parentheses.Stack usagePush opening brackets and pop on closing ones.
Find the missing number in an array.Math or XORUse sum formula or XOR approach.
Find the majority element.Voting algorithmUse Boyer-Moore majority vote.
Rotate an array by k positions.Array manipulationReverse in place or use modular indexing.
Move all zeros to the end.Two pointersMaintain a pointer for the next non-zero.
Find the intersection of two arrays.Set operationsUse hash set for faster lookup.
Count the number of islands in a grid.DFS/BFSTraverse connected land cells and mark visited.
Check if a binary tree is balanced.Tree traversalUse recursion and height check.
Find the lowest common ancestor in a binary tree.Tree reasoningUse recursion based on node positions.
Perform level-order traversal of a binary tree.BFSUse a queue.
Detect a cycle in a linked list.Fast/slow pointerUse Floyd’s tortoise and hare.
Reverse a linked list.Pointer manipulationIteratively update next pointers.
Implement LRU cache.Data structure designUse hashmap + doubly linked list.
Find the k-th largest element in a stream.Heap logicUse a min-heap of size k.
Top K frequent elements.Heap and hash mapCount frequencies and use a heap.
Find all pairs whose sum equals target.Hash mapStore seen numbers and look for complements.
Find the longest common prefix.String comparisonCompare each string with the first.

Detect whether a graph has a cycle.DFS/Union-FindTrack visited states and parent relations.
Convert decimal to binary.Bit manipulationUse repeated division.
Count set bits in an integer.Bit manipulationUse bitwise shift and mask.
Find the power of two.Bit trickCheck if n & (n - 1) is zero.
Find if a number is a palindrome.Math / stringReverse digits or compare digits from both ends.
